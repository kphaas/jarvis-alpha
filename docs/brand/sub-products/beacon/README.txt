BEACON
part of the AT0 sub-product brand family

ROLE
----
Beacon is Alpha's internet evidence broker. It finds public-source signal while
staying inside a protected policy boundary.

MARK
----
The mark keeps the AT0 family ring and teal node. The center glyph combines:
  * shield boundary       = protected policy perimeter
  * vertical beacon beam  = current public evidence
  * compass reticle       = source orientation

FILES
-----
