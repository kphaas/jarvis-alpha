01Brand Essence

AT0 is a private, always-on intelligence that runs every domain of your life from one beacon. The brand should always feel like a trusted machine — advanced, calm, and in control.

Attributes

  • Signal Teal = intelligence, scanning, motion
02The Logo

The primary logo is the AT0 wordmark: "AT" in warm-tint Chakra Petch + the beacon mark as the "0". This is the locked, preferred form everywhere there is room.

AT
Primary logo · use this first

Anatomy — what each part means

  • The ring (0) — a closed beacon ring in amber. The constant, trusted presence.
  • The core — the glowing center; the brain.
  • The teal scanning node + trail — intelligence always working. Never recolor or remove it.
  • The sonar ping — a broadcasting beacon (digital/animated only).
  • "AT" warm tint — warm-white fading to faint amber. Subtle, never a hard gradient.

⚙️ Live vs static: use the animated mark (ping + sweep) in digital surfaces. For print, favicons, and tiny sizes, use the static mark — ring + core + teal node at rest, no motion.

04Clear Space & Minimum Size

Clear space

Keep padding equal to X = the diameter of the "0" on all sides. Nothing intrudes.

  • Symbol only — no smaller than 24px

06Naming — AT0 vs "Auto"

One product, two names. AT0 is how it's written. "Auto" is how it's spoken.

Write it: AT0

  • Logos, headlines, UI labels, legal, code, file names
  • Capital A, capital T, numeral 0 (zero)
  • No hyphen, no space, no period

Say it: "Auto"

  • Voice UI, conversation, taglines, casual reference
  • Capitalized like a name: Auto
  • First mention in copy: AT0 ("Auto"), then either

09Motion

Motion is part of the identity — but it's slow and confident, never frantic. The brand breathes; it doesn't flash.

Sweep

Teal node circles the O. ~3s per rotation. Steady, like a scanner.

Ping

Amber ring radiates outward every ~2.8s. The beacon broadcasting.

Respect reduced-motion

Always honor prefers-reduced-motion — fall back to the static mark.
