NOTES
-----
• "AT" letters are OUTLINED (vector paths) — no font needed to display.
• Fonts used in the brand: Chakra Petch (display), Hanken Grotesk (body),
  Space Mono (technical). All free on Google Fonts.
• Animated SVGs play when opened in a browser; use static versions for
  print, favicons, and any reduced-motion context.
• Write it "AT0" (capital A, capital T, numeral zero — no hyphen/space).
  Say it "Auto".
