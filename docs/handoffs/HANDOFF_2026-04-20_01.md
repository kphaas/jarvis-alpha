## Debugging Journey (for future reference)

Temporal v1.30.4 server required **7 attempts** before starting cleanly. Each attempt surfaced a different config-loading bug. Here's the full chain for future Temporal upgrades:

| # | Error | Root cause | Fix |
|---|---|---|---|
| 1 | `cannot unmarshal !!map into string` | Go template not activated | Add `# enable-template` marker in first 1KB |
| 2 | `cannot unmarshal !!str '<no value>' into int` | Wrong sprig syntax | `{{ .Env.X }}` → `{{ env "X" }}` |
| 3 | `failed to get config files: no config files found` | Leading `/` stripped from `--config` absolute path | Use `--config-file` flag (non-deprecated) |
| 4 | `flag provided but not defined: -config-file` | urfave/cli strict ordering | Global flags MUST precede subcommand |
| 5 | `ringpop config malformed broadcastAddress param` | Ringpop rejects DNS hostnames | Resolve hostname→IP at script startup |
| 6 | Crash loop at 60s, `context deadline exceeded` | Internal worker can't reach frontend (bindOnIP on Tailscale, publicClient on loopback) | Simplify to loopback-only for single-node |
| 7 | ✅ SUCCESS | — | — |

**Plus UI debugging (4 attempts):**
1. `${VAR}` in YAML didn't substitute → ui-server doesn't support Go template rendering
2. Random port instead of 8233 → `port:` missing from YAML when it was hardcoded
3. Leading-slash bug on UI `--config` flag → `cd` into parent dir, use relative path
4. ✅ SUCCESS with perl render-from-template pattern

**Key learnings captured for future sessions:**
- Temporal server v1.30.4: `# enable-template` marker + `{{ env "X" }}` sprig syntax
- Temporal server: use `--config-file <absolute-path>` (global flag, before `start`)
- Temporal ringpop: requires numeric IP, not DNS hostname
- Single-node Temporal: `broadcastAddress: 127.0.0.1` is documented + supported
- Temporal UI server: does NOT support Go template substitution; env vars are overrides for specific keys only
- macOS: no `getent`, no `timeout`, no `envsubst` by default; use `dscacheutil`, background+kill, and `perl` instead
