## Stage 3 — SECURITY DEFINER Functions (DONE)

Three fix rounds; each caught real bugs.

### Round 1 — Original migration (`37d1d15`)

Seven functions created (later six after promote rip):

1. `record_buddy_event(TEXT, …, JSONB)` — initially wrong types.
2. `evict_expired_working_memory()` — used non-existent `expires_at`.
3. `evict_episodic_memory_older_than(TEXT, INTEGER)`
4. `cap_episodic_memory(TEXT, INTEGER)`
5. `cap_semantic_memory(TEXT, INTEGER)`
6. `promote_episodic_to_semantic(TEXT)` — wrong target table schema (later ripped).
7. `run_buddy_memory_maintenance(TEXT)` — JSONB omnibus; inner try/catch per step.

All owned by `jarvisbrain`, `SECURITY DEFINER`, `search_path = pg_catalog, public, pg_temp`. Per Perplexity validation: `SET LOCAL lock_timeout='2s'` + `statement_timeout='10s'` inside body; `REVOKE EXECUTE FROM PUBLIC`; `GRANT EXECUTE` to `jarvis_alpha_writer` + `jarvisbrain`. Re-raise SQLSTATE `23xxx` / `40xxx`; catch others as `WARNING` + `RETURN 0`/`NULL`.

**Code:** `buddy_agent.py` — `_write_event` calls `SELECT public.record_buddy_event(...)`; `_run_cycle` replaced six raw writes with one `SELECT public.run_buddy_memory_maintenance(user_id)` per user. `approval_notifier.py` — raw `INSERT` replaced with `SELECT public.record_buddy_event('system', ...)`.

### Round 2 — `record_buddy_event` schema fix (`5a4c734`)

Smoke test: priority is `INTEGER` not `TEXT`; `id` is `UUID` not `BIGINT`; `user_id` nullable. Real `alpha_buddy_events` priority scale: 1=low (94), 2=normal (24, default), 3=high (4504). `event_type` CHECK: `alert` \| `reminder` \| `suggestion` \| `system`.

Migration `20260408_140000_record_buddy_event_fix.sql`: drop old function; recreate with `p_priority INTEGER`, `RETURNS UUID`; drop bad NULL validation. Python: `_normalize_buddy_priority()`, `_normalize_buddy_event_type()` (eviction/promotion/maintenance → `system`); `_notif_priority_int()` in notifier.

### Round 3 — Evict fix + promote rip (`0b36100`)

- `evict_expired_working_memory`: real schema uses `tier` + `persistent` + `created_at`, not `expires_at`. Rewrote to `DELETE ... WHERE tier='working' AND persistent=false AND created_at < now() - interval '24 hours'`. TODO: make 24h configurable when memory goes production.
- `promote_episodic_to_semantic`: `alpha_semantic_memory` schema incompatible (needs LLM pipeline). **Ripped.** TD-40 tracks redesign. Near-zero production rows (`alpha_semantic_memory` has 0).
- `run_buddy_memory_maintenance`: shrunk from five ops to four (no promote step).

Migration `20260408_150000_evict_fix_and_promote_rip.sql`: `DROP FUNCTION promote_episodic_to_semantic`; `CREATE OR REPLACE` evict + maintenance.

**Smoke test final: all 10 tests passed.**

### Lesson locked

**Schema verification (`\d tablename`) is mandatory** before any function touching a table. Cost: two fix rounds. Adding to prompt template.
