## What Shipped This Session

### 1. GATEWAY_URL Centralized — JARVIS Invariant Enforced
- Removed hardcoded `:8282` fallback from three files: `brain/core/config.py`, `brain/routes/mesh.py`, `brain/routes/unifi.py`
- `config.py` now uses `os.environ["ALPHA_GATEWAY_URL"]` — fail-loud, no fallback (12-Factor standard)
- `mesh.py` and `unifi.py` import from `brain.core.config` — single source of truth
- Raw IP `100.112.63.25` removed from all Python runtime code
- Live DB fixed: `alpha_node_registry` Gateway row updated `:8282` → `:8283`
- Corrective migration `008_fix_gateway_health_url.sql` added (does not edit applied 007)
- Commits: a73b4dd

### 2. Council Panels — Post-Hoc Review Only
- Council panels no longer stream live during model execution
- Panels appear only AFTER synthesis is complete — designed as a human cross-check tool
- `councilStreams` removed from message rendering during streaming
- `council_detail` set via `onDone` callback with `councilAccum` fallback
- `hasLiveStreams` logic removed from MessageBubble

### 3. Apple-Style Scroll
- Replaced per-message-type scroll logic with one universal rule: respect user scroll position
- `isAtBottom` state tracks if user is within 60px of bottom
- Auto-scroll only fires when `isAtBottom === true`
- Floating ↓ pill appears when user is scrolled up — tap to jump to bottom
- Council mode forces `isAtBottom = false` after send — holds scroll position during synthesis
- Removed `lastMsgRef`, `wasCouncilRef`, `councilStreaming` — all replaced by one pattern

### 4. New-Thread Blank Message Fix
- Root cause: `useEffect([threadId])` fired when `onThreadCreated` updated the prop during streaming
- This fetched messages from DB and overwrote the in-progress streaming response with empty/stale data
- Fix: skip message fetch if `streaming || sendingRef.current`

### 5. Double-Send Nuclear Guard
- Added `window.__jarvisSending` global flag — survives React component tree re-renders
- Set at top of `send()`, cleared in `onDone`, `onError`, and early-return guard
- Prevents duplicate sends regardless of event handler source

### 6. Council Toggle Labels
- Toolbar button: "Show Council" / "Hide Council" (was "Show thinking" / "Hide thinking")
- Per-message: plain text status "Showing Council" / "Hiding Council" (was a clickable button)
