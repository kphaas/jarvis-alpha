### Three SSH propagation issues from Apr 28 hardware swap

1. **Air → Sandbox magic DNS** — known_hosts had old fingerprint. Cleaned via ssh-keygen -R + ssh-keyscan.
2. **Sandbox → Brain + Sandbox → Gateway** — new Sandbox pubkey not in `authorized_keys` on either. Fixed by appending pubkey on Brain (in interactive session) and on Gateway (proxied through Air).
3. **Air → Sandbox commit-script key (`macair_jarvis`)** — pubkey IS installed but commit script's `SSH_OPTS[]` array doesn't reliably pass `-i` flag. Result: passwordless test works, real commit prompts. Captured as TD-171.

All resolved this session. Captured as TD-169 / TD-171 / TD-173.

### Big-tech security gate that actually worked

When Sandbox first SSH'd to Brain after hardware swap, Claude Code refused to TOFU the host key — instead halted, dumped the fingerprint, asked for verification. We verified out-of-band: `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` on Brain matched `ssh-keyscan` from Air. Same protocol applied to Gateway. **Standard NIST 800-53 IA-3.** Zero TOFU compromises.
