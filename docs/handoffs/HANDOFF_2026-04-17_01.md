## Architecture Decisions Locked

### Scope Taxonomy (Capability-Based, precedent: dream.kill)

| Scope | Purpose | Who has it |
|---|---|---|
| dream.execute | Session lifecycle (start, steps, complete) | gateway |
| dream.plan | Invoke planner (cloud cost, no state mutation) | gateway |
| dream.review | Invoke reviewer (cloud cost, no state mutation) | gateway |
| dream.kill | Emergency kill switch | gateway |
| cloud.call | Brain outbound to Gateway /v1/cloud/call | brain |

**Rationale:** Blast radius differs — plan/review burn budget, session routes mutate state. Different threat models → different scopes. AWS IAM / Stripe / Google Cloud all follow this pattern.

### Two-Token Pattern for Brain

- `ALPHA_BRAIN_SERVICE_TOKEN` — Brain's outbound service-to-service token (iss=brain)
- `ALPHA_BRAIN_TOKEN` — Brain's user-facing token (issued to authenticated users)

Gateway only has ONE (`ALPHA_SERVICE_TOKEN`) because Gateway only calls out. Brain has two because Brain serves AND calls out.

### Gateway /v1/cloud/call Contract

**Request envelope:**
```json
{"provider": "claude|gemini|perplexity", "payload": {<provider-native args>}}
```

**Response envelope:**
```json
{"provider": "...", "result": {<provider-native response>}}
```

**Provider name mapping in llm_transport:** `anthropic → claude`, `google → gemini`, `perplexity → perplexity` (Gateway adapter registry uses short family names).

### Per-Provider Text Extraction (in llm_transport._extract_text)

- **Claude:** `result.content[0].text` (Anthropic Messages API)
- **Gemini:** `result.candidates[0].content.parts[0].text`
- **Perplexity:** `result.choices[0].message.content` (OpenAI-compatible)

### Postel's Law for LLM JSON Parsing

`planner.py::_strip_markdown_fences()` defensively strips ```json or bare ``` wrappers from LLM output. Paired with strengthened prompt that forbids fences. Be liberal in what you accept, conservative in what you send.

### Cross-Family Planner/Reviewer Enforcement

Migration sets `CHECK (planner_family <> reviewer_family)` at DB level. Seeded default: Claude plans, Gemini reviews. Not an accident — forces two independent model heads to validate each plan. AWS principle of "don't let one vendor own the decision loop."

### Cost Multiplier = 2.5x

Perplexity validation cited real overruns 3-5x typical, not 1.5x. Conservative estimate on LLM output cost. TD-81: calibrate after 2-week observation.

### Dev Server Sufficient for Temporal (Alpha-2 rewrite)

No Docker — Homebrew ARM only. Single `default` namespace. Single omnibus worker. Isolated `temporal` DB on Brain Postgres (not `jarvis_alpha`).

## Known Gotchas That Bit Us This Session

### 1. "Pull required on Brain Gateway Endpoint" — I missed it twice

Gateway didn't get commits `d99560f` and `2c2bfca` until we hit the rotation bug. **TD-88 fixes this.**

### 2. `source ~/jarvis/.secrets` doesn't export by default

Python subprocess can't see vars. Fix: `set -a; source ...; set +a`. LaunchAgents don't need this — only interactive shell verification.

### 3. Ruff reformats heredoc code → string-match patches fail silently

Two test-patch attempts failed because ruff had reformatted `await planner.plan(...)` onto two lines. Heredoc rewrite of entire function blocks more reliable than `python3 -c` with embedded strings.

### 4. Gateway adapter key ≠ provider canonical name

Gateway `_adapters` registry uses `"claude"`, `"gemini"`, `"perplexity"`. Our code was sending `"anthropic"`, `"google"`. Fixed via `_GATEWAY_PROVIDER_MAP` in llm_transport.

### 5. Anthropic API response shape — not flat

Expected flat `{content: "..."}` but actual shape is `{content: [{type: "text", text: "..."}]}`. Per-provider `_extract_text()` now handles all three providers.

### 6. FastAPI error responses vs success responses

FastAPI returns `{"detail": ...}` on errors. Success has `{"provider": ..., "result": ...}`. Check `if "detail" in parsed and "result" not in parsed` to disambiguate.

### 7. Hardcoded model names in test fixtures

`_policy()` fixture uses generic `"claude-haiku"` (correct). One test used full `"claude-haiku-4-5-20251001"` (wrong). Now consistent. Good catch by Ken.

### 8. `service_identity.py` DEFAULT_SCOPES is source of truth

Rotation script reads from this at runtime. NO per-node overrides. Add a scope there, rotate token, restart service.
