## Key Architecture Decisions Locked

### Service Identity (Doc 1)
- Per-node RS256 keypairs, iss-based direct lookup, VALID_ISS_ACTOR_PAIRS
- 7-day service tokens, 30-day user tokens, auto-rotate every 6 days
- jti on all tokens for future deny-list, no age in child JWT (PII)
- Undecorated routes default to require_scopes(["*"]) — deny by default
- Child content filter as middleware, not route handler

### Approval Gateway (Doc 2)
- T1 (auto) through T5 (PIN confirm), unclassified defaults to T5
- Overnight T4/T5 always queued — never auto-execute
- Budget: $2/night, 50 calls, 0 deploys, max 5 overnight pre-approvals
- Immutable audit (REVOKE DELETE/UPDATE), nonce replay protection
- Auth before classification, audit INSERT failure blocks execution

### RLS Rollout (Doc 3)
- 1 table → 15 tables, child safety DB-enforced
- current_setting with true fallback, sentinel _none for unauth
- One Postgres role (jarvis_alpha_app) — all via RLS, not GRANT/REVOKE
- Buddy: SELECT + UPDATE on memory only (no INSERT/DELETE)
- Adult approvers see ALL pending (spouse can approve)

### Claude Code Integration (Doc 4)
- Claude Code is a tool, not an agent — Forge orchestrates
- Uses Forge's service token — no own identity
- **P0: macOS Seatbelt** — kernel-level filesystem sandbox, blocks ~/.pki/ access
- **P0: Git pre-push hook** — blocks main push when CLAUDE_CODE_SESSION set
- **P1: Three-layer review** — ruff+bandit hard gate → different-model reviewer → Ken
- Gateway bypass justified (dev tool exception)
- Pass/fail reviewer, lesson cache, no REST API for V1
- Gate: no unsupervised overnight until Seatbelt + hooks installed

### Middleware Stack (final)
```
CORS → Auth → Scopes → RLS → RateLimit → route handler
```
