## Phase B2c — Cost Event Route + RLS

### New Route: `POST /v1/internal/cost-event`

File: `brain/routes/internal_cost.py`

- Accepts `CostEvent` Pydantic model (provider, model, tokens, session_type, executor, on_behalf_of)
- Looks up pricing from `alpha_model_pricing` table (most recent `effective_from <= today`)
- Calculates `cost_usd` using Decimal math (no float rounding)
- Inserts into `alpha_cloud_costs` with `source_request_id` from trace middleware
- Scoped to `cost.report` — only Gateway service token can call it
- Graceful degradation: if no pricing row found, `cost_usd = 0` with `PRICING_MISS` warning log

### RLS Fix (TD-65)

Migration: `20260416_170000_cloud_costs_rls.sql`
- `cloud_costs_isolation` policy: `jarvis.role = 'platform_admin'` for ALL
- Route sets GUC via `set_config('jarvis.role', 'platform_admin', true)` in transaction before INSERT
- Pattern matches `alpha_approval_audit` RLS

### Service Identity Updates

- `scripts/service_identity.py`: added `cost.report` to Gateway DEFAULT_SCOPES
- Gateway service token regenerated with `cost.report` scope
- Auto-rotation LaunchAgent already running (`com.jarvis.alpha.rotate.gateway`) — will pick up new DEFAULT_SCOPES on next rotation

## Phase B3 — Gateway Cost Emitter

### New File: `gateway/cost_emitter.py`

SQLite WAL buffer with background flush loop:

- `buffer_event()` — fire-and-forget, never blocks adapter flow, writes to SQLite
- `flush_loop()` — asyncio background task in Gateway lifespan, 50-event batches, 5s sleep
- `_flush_sync()` — curl + asyncio.to_thread to Brain (Tailscale TLS safe)
- DB path: `~/jarvis-alpha/data/cost_buffer.db`
- Successfully flushed events are DELETEd from SQLite

### Adapter Changes

- `base_adapter.py`: added `_emit_cost()` helper method — calls `buffer_event()` in try/except (never raises)
- `claude_adapter.py`: extracts `usage.input_tokens` / `usage.output_tokens`, calls `_emit_cost()`; **provider_name() changed from "claude" to "anthropic"** to match CHECK constraint
- `perplexity_adapter.py`: extracts `usage.prompt_tokens` / `usage.completion_tokens` / `usage.total_tokens`
- `gemini_adapter.py`: extracts `usageMetadata.promptTokenCount` / `usageMetadata.candidatesTokenCount`

### Gateway App Changes

- `gateway/app.py`: imports `flush_loop`, creates background task in lifespan, cancels on shutdown

## Phase B4 — Dream Orchestrator Routing Fix

### Problem

Orchestrator (runs on Gateway) called `BRAIN_URL/v1/cloud/call` — but `/v1/cloud/call` only exists on Gateway. All cloud dispatch was broken.

### Fix

- `_dispatch_cloud()`: now imports and calls Gateway adapters directly (same process). Cost emission happens automatically via `_emit_cost()`. No double counting — `cost_usd: 0` in step result because real cost is tracked via cost_emitter.
- `_dispatch_llm()`: now calls Brain's `/v1/ask` endpoint instead of non-existent `/v1/cloud/call` with provider "ollama"
- Added per-step cost pre-check: before dispatching a `cloud` step, re-queries `next-step` to check if budget is exceeded

## End-to-End Verification

Verified the full pipeline with a real Claude API call:

1. Gateway curl → `/v1/cloud/call` with provider "claude"
2. ClaudeAdapter calls Anthropic API → gets response with `usage.input_tokens=9, output_tokens=5`
3. `_emit_cost()` buffers event to SQLite WAL (`cost_buffer.db`)
4. Flush loop picks up event, POSTs to Brain `/v1/internal/cost-event`
5. Brain looks up pricing for `anthropic/claude-haiku-4-5-20251001` → finds row
6. Calculates `cost_usd = 0.000034` (Decimal math)
7. Inserts into `alpha_cloud_costs` with `source_request_id` from trace

```
-----------+---------------------------+---------------+-------------------+----------

```
