## Architectural Decision — bash 5 Pinning

Discovered mid-ship: `local -n` (nameref) requires bash 4.3+. macOS ships bash 3.2.57 at `/bin/bash` for licensing. First Brain run failed loud at runtime version guard.

**Decision:** Pin Homebrew bash 5 across JARVIS infra. Big-tech standard (GitHub Actions, Google, Meta all pin modern bash for tooling). Homebrew is already baseline on every JARVIS node (Postgres, Ollama, nginx all from brew).

**Implementation:**
- Shebang on smoke scripts: `#!/opt/homebrew/bin/bash`
- Runtime guard in smoke_lib.sh: asserts `${BASH_VERSINFO[0]} -ge 5`, exits loud on mismatch
- Install: `brew install bash` on Brain + Sandbox (both confirmed bash 5.3.9)

---

## Lessons Locked

1. **Shebang only fires on direct execution.** `bash script.sh` forces `/usr/bin/bash` (3.2 on macOS) and bypasses `#!/opt/homebrew/bin/bash`. Always invoke smokes as `~/path/script.sh`, never `bash ~/path/script.sh`. Runtime version guard caught this — belt-and-suspenders design validated.
2. **Sandbox Claude must run discovery BEFORE design when bash version matters.** `local -n` was specified in design without checking target runtime bash version. Discovery should include `/bin/bash --version` on every node we'll execute on.
3. **Dependency injection beats configuration** for shared shell libs. Caller owns auth, lib owns behavior. Matches GitHub/Vault/Consul patterns. Rejected DSN-only and dual-flavor APIs.
4. **shellcheck baseline before lib design pays off.** Pre-existing SC1090 (dynamic source) and SC2015 (`A && B || C`) findings became explicit "don't reintroduce" rules in design §5–§6.
5. **Pull script silent failure is a real risk.** `jarvisalpha_pull.sh` reported success while `git pull --rebase` had errored on unstaged changes (TD-59 logged).

## Brain Pull Recovery — Procedure Captured

After scp staged files to Brain pre-commit, post-commit pull failed because scp'd files = uncommitted local changes. Recovery sequence:
mv scripts/smoke_lib.sh /tmp/smoke_lib.sh.brain_local
git stash push scripts/smoke_5d1_watchdog_agent.sh scripts/smoke_task_events_insert.sh
git pull origin main --rebase
diff /tmp/smoke_lib.sh.brain_local ~/jarvis-alpha/scripts/smoke_lib.sh && echo "LIB_IDENTICAL"
git stash drop
rm /tmp/smoke_lib.sh.brain_local

Verify equivalence (`LIB_IDENTICAL` printed) before discarding stash. Untracked files needing manual move because `git stash --include-untracked` would sweep too broadly (logs/, vault_storage/).

**Future avoidance:** Don't scp pre-commit. Either commit first then pull, or accept ephemeral test on test node only.
