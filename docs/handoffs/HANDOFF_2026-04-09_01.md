## Lessons Locked Tonight

1. UI smoke tests catch what unit smoke tests miss. Stage 5b hotfix bug only existed at the integration layer — `SET ROLE` path wasn’t covered by Stage 5a’s function-level smoke test. Always run real-world end-to-end smoke before walking away from a cutover.
2. Stowaway commits exist. Always check `git log origin/main..main` before pushing main. `f33e3ce` had been sitting on local main for four days unnoticed.
3. Sandbox Claude is real engineering capacity. With a clear runbook and disciplined phase gates (discovery → design → review → implement → review → commit), it executes complete stages. Phase 1 discovery in particular catches things Air Claude misses because it has direct file access.
4. Discovery before design — every time. Stage 5b would have shipped broken without discovering the empty-username DSN. Stage 5c would have shipped broken without discovering `_expire_pending_approvals`. Discovery time is never wasted.
5. Independent rollback isolation matters. Splitting `ALPHA_DB_DSN_WRITER` and `ALPHA_DB_DSN_BUDDY` into separate env vars means buddy can be reverted without touching FastAPI and vice versa. One env var per service, not one per role.
6. Lint enforcement is not optional. When ruff was missing on Sandbox, the right answer was install it, not skip it. Skipping the rule once normalizes skipping it always.
