- alpha_buddy_events CHECK constraint only allows event_type IN ('alert', 'reminder', 'suggestion', 'system') — rotation failure alert uses 'token_rotation_failed' which will fail the constraint. Need to ALTER TABLE to add it, or change the event_type to 'alert'.
- rotate_service_token.py alert_failure INSERTs severity, source, payload columns into alpha_buddy_events — table doesn't have these columns. Alert INSERT will fail silently. Needs schema alignment.
- Unclassified routes returning 403 includes some UI-facing routes (security panel, mesh certs, logs) — UI will show errors on those pages until Phase 2 or until routes are added to ROUTE_CLASSIFICATION.
- Service tokens expire April 12 — auto-rotation LaunchAgents will fire ~April 10.
- Approval middleware T2/T3 audit write is fire-and-forget (non-blocking) — per spec, T4/T5 audit INSERT failure must BLOCK execution (Phase 2).
