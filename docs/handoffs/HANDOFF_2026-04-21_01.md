## Key research findings that shaped decisions

### State/compute split is the big-tech pattern
- AWS RDS runs on dedicated EC2 (bare-metal RDS available as of 2025), ECS runs containers
- GCP Cloud SQL on managed VMs, GKE containers
- Azure SQL on Hyper-V VMs, AKS containers
- Netflix Cassandra on EC2 AMIs (not Titus containers)
- Meta MySQL on bare metal, Tupperware containers

### Postgres in Docker on macOS: 2–4× slower
Reported across multiple sources due to hypervisor + filesystem indirection. Docker's own docs position Postgres-in-containers as "local dev" pattern, not production.

### Kubernetes operators (CloudNativePG, Crunchy, StackGres) are the 2026 path IF Kubernetes
We don't have Kubernetes at 3-node scale → state native is correct call.

### OrbStack wins on Apple Silicon
- ~1.1 GB idle RAM vs Docker Desktop's ~3.2 GB
- 2s startup vs 15–30s
- Drop-in Docker API compatibility
- `host.docker.internal` works natively → enables container-to-host-Postgres pattern

### Infisical / Bitwarden over HashiCorp Vault for 10 secrets + solo operator
Vault is overkill. Both alternatives match AWS Secrets Manager / GCP Secret Manager patterns at appropriate scale.

## Lessons from this session

1. **Perplexity cross-check for every non-trivial architecture decision pays off.** Today Perplexity refined the secrets pattern (per-service file split + file mounts over env vars) and caught the image-tag centralization opportunity I missed.

2. **"What would big tech do?" is the right filter.** Initial reflex was "containerize everything." Research showed big tech explicitly splits state from compute. Saved us from the Postgres-in-Docker performance penalty + Ollama Metal-GPU loss.

3. **Reading the git diff without verifying against HEAD caused confusion.** Earlier today when the migration failed, I diagnosed the wrong root cause because I trusted the staged diff without checking what was actually in the latest commit. System had already self-healed.

4. **Downloads don't auto-transfer from Claude artifacts.** Each artifact must be individually clicked to save to Downloads. Tripped on this — cost ~2 interactions.

5. **`render_events.py` can't parse multi-line error boxes.** Box-drawing characters in JSON error field break the parser. Low-priority bug but should be fixed before Alpha-5 runs (more Compose errors will exercise this path).
