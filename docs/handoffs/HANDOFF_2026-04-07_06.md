### Migration File (Step 7)

`YYYYMMDD_HHMMSS_create_writer_role_and_security_definer_fns.sql`:

1. `CREATE ROLE jarvis_alpha_writer NOLOGIN INHERIT NOBYPASSRLS`
2. Grant minimal privileges (USAGE on schema, no direct table access)
3. Create SECURITY DEFINER functions:
   - `record_buddy_event(event_type, graph_id, step_id, message, priority)` → writes to `alpha_buddy_events`
   - `record_watchdog_event(node, service, status, details)` → writes to `alpha_watchdog_events`
   - `update_task_step_state(step_id, new_state, error_msg)` → updates `alpha_task_steps`
   - `complete_graph(graph_id, final_state, summary)` → updates `alpha_task_graphs`
   - `evict_stale_working_memory(cutoff_ts)` → for Buddy memory eviction
   - `promote_episodic_to_semantic(min_score)` → for Buddy promotion
4. All functions: `SECURITY DEFINER`, `SET search_path = public, pg_temp` (mandatory hardening), owned by `jarvisbrain`
5. `GRANT EXECUTE ON FUNCTION ... TO jarvis_alpha_writer`
6. Revoke all default `PUBLIC` execute privileges

### Python Refactor

Each agent stops calling `asyncpg.create_pool(dsn)` directly. Instead:
- Connect with new `WRITER_DSN` (uses `jarvis_alpha_writer` role)
- Replace direct INSERTs/UPDATEs with `SELECT record_buddy_event(...)` calls
- Function defines the contract; agent code just supplies parameters

## Lessons Locked Tonight

1. **Self-critique works.** Catching my own plan flaws (legacy subdir, deferred baseline, misleading phases) before writing the prompt saved an hour of rework.
2. **Perplexity validation pays off.** Two validations tonight (TD-1 fix + migration consolidation) — both produced real corrections.
3. **Discovery before design.** The Step 7 inspection prompt surfaced 3 parallel migration systems, 2 dead watchdogs, and TD-12 verification need. Without it, Step 7 would have been built on broken foundations.
4. **One cohesive commit beats many tiny commits when everything interlocks.** Phase 1 was 17 files in one commit because splitting created broken intermediate states.
5. **Don't narrate routing.** Just execute. Style preference noted from earlier session, applied throughout tonight.
6. **Ask before writing Cursor prompts.** New process rule, kept consistently after the early reminder.
7. **Big tech standard for migrations:** raw SQL with checksum tracking + bash runner is fully production-grade at this scale. Alembic isn't more "enterprise" — it's a different tool with different tradeoffs.
8. **macOS BSD `date` doesn't support `%N`.** Always Python for ms timing on Darwin.
9. **`set_config(..., true)` is transaction-scoped** — known from Step 5, reinforced tonight.
10. **Output reduction matters.** ~50 lines → ~15 lines on commit success. Less noise = faster error spotting.
