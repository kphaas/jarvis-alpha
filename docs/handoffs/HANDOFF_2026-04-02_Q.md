### 5. TaskGraph Schema — Migration 006

File: brain/db/migrations/006_task_graphs.sql

Two tables:
- alpha_task_graphs: id, title, created_by, source (manual/agent), status, ci_required, ci_passed, checkpoint, timestamps
- alpha_task_steps: id, graph_id, label, depends_on (uuid[]), status, retry_count (max 3), executor, tool, input/output (jsonb), error, checkpoint, timestamps

Architecture locked:
- Full DAG — depends_on is array of step UUIDs, empty = root
- Ken-created: ci_required=false. Agent-created: ci_required=true
- Step retry: 2 retries → halted on 3rd failure
- Graph states: pending → running → halted/complete
- Step states: pending → running → failed → retrying → complete/halted/skipped

RLS: task_graphs_isolation + task_steps_isolation policies applied.

**TaskGraph engine (planner, executor, routes) NOT YET BUILT — schema only.**
